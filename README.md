# Clement Idongesit Sunday — Student Portfolio and Academic Manager

Multi-page responsive website built with plain HTML, CSS and JavaScript (no build step).

Pages: index, about, skills, projects, academics, planner (add / complete / delete tasks + CGPA calculator), contact.

## Run locally
Open `index.html` in a browser.

## Host free on GitHub Pages
1. Create a repo and upload everything in this folder (keep `index.html` at the root).
2. Repo Settings > Pages > Deploy from branch > `main` / root > Save.
3. Your link will be `https://<username>.github.io/<repo>/`.

## Before submitting
- Edit `build.py` text if you want to change content, then run `python3 build.py`.
